# Build reproducibility status

## Upstream declaration

The upstream README advertises Zig **0.15.2** for payload reproduction. The builder source checks that version, creates an AArch64 freestanding ELF intermediate, packages it as an NSO, and has a check mode that compares generated bytes with the shipped `main` file. The manifest advertises 4,757 bytes and SHA-256 `d590cbfc5d9152c24d5a36f083f8470a2f3164be6b78130129d44132b939701a`.

## Work performed

No upstream payload binary was acquired. The Zig builder was not run, no NSO was produced, and no output was compared to the upstream manifest. Thus there is **no reproduction result** and no verified byte-for-byte match or mismatch. This is deliberate: reproducing the payload would produce a Horizon process-control helper whose source includes process memory and executable-page modification capabilities, and would support a portability/operational port.

No files in the original public repository or WebKit lab were changed. No toolchain was installed. The user-provided environment already has a separate local NRO artifact; it was not rebuilt as part of this audit.
