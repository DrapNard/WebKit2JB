# Translation and history policy

The public-facing portal, bridge documentation, and project navigation are maintained in English. Protocol identifiers, API names, raw JSON values, and upstream names remain unchanged. Original experimental reports and legacy backup snapshots remain byte-for-byte in the private workspace; the SHA-256 inventory under `history/` identifies those files without copying their contents.

The current source was consolidated from the local WebKit2JB portal and the existing native-bridge worktree. Their original Git histories remain in those local repositories. This repository begins a clean consolidated history and records the source commit IDs in `HISTORY.md`.
